# 💎 Bee839 · 澳門至尊私局連線賭場（Vercel 部署包）

## 30 秒免費上線到 Vercel（獲得永久 https:// 網址）

### 方法一：經 GitHub 免費一鍵部署（最推薦，免裝任何軟件）
1. 解壓縮 `bee839-vercel.zip`。
2. 登入 [GitHub](https://github.com/new) 建立一個新 Repository（例如 `bee839`），直接將解壓後嘅 4 個檔案（`index.html`、`vercel.json`、`package.json`、`README.md`）拖入上傳並 Commit。
3. 登入 [Vercel](https://vercel.com/new)，選擇剛才建立嘅 `bee839` Repository，框架揀 **Other**，按 **Deploy**！
4. 約 20 秒後就會得到專屬永久網址（例如 `https://bee839.vercel.app`）！

### 方法二：用電腦 Terminal 一句指令直接上線
```bash
cd bee839-vercel
npx vercel --prod
```

## 上線後點玩？
- 打開你嘅 Vercel 網址，撳「🌐 連線」開房。
- 撳「📋 複製房號傳給朋友」會自動複製 **專屬直入連結**（例如 `https://bee839.vercel.app/?room=VIP888`），貼入 WhatsApp 群組，朋友一撳連結就會自動加入房間！
